# Financial Transactions EDA, ML & Power BI Dashboard

This project analyzes a messy financial transaction dataset through data cleaning, exploratory data analysis (EDA), machine learning, and interactive Power BI dashboards.

The project focuses on cleaning inconsistent transaction data, extracting revenue insights, analyzing transaction patterns, and testing machine learning models for transaction outcome prediction.

## Project Workflow

Data Cleaning → EDA → Feature Engineering → ML Modeling → Power BI Dashboard
