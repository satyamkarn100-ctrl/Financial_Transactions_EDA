# Financial Transactions EDA, ML & Power BI Dashboard

This project analyzes financial transaction data through data cleaning, exploratory data analysis (EDA), machine learning, and interactive Power BI dashboards.

The project covers data preprocessing, revenue and transaction analysis, feature encoding, machine learning model evaluation, and business-focused data visualization.

## Project Workflow

Data Cleaning → EDA → Feature Engineering → ML Modeling → Power BI Dashboard

## Folder Structure

Financial_Transactions_EDA/
├── data/         ← CSV file(s) with financial transaction data
│     └── dirty_financial_transactions.csv
├── notebooks/    ← Jupyter notebook(s) with EDA + ML code
│     └── ml_models.ipynb
├── scripts/      ← Optional helper Python scripts
├── Power-BI/     ← Power BI dashboard and related files
└── README.md     ← This README file

## Key Analysis

### Exploratory Data Analysis

- Analyzed transaction revenue and transaction status
- Examined payment methods and product-level revenue
- Performed data cleaning and preprocessing
- Analyzed monthly, yearly, and weekday revenue trends
- Investigated transaction patterns and revenue distribution

### Machine Learning

Machine learning models were developed to analyze and predict transaction outcomes.

The workflow includes:

- Feature encoding
- Data preprocessing
- Model training
- Model evaluation
- Comparison of model performance

### Power BI Dashboard

An interactive Power BI dashboard was created to present the financial transaction analysis in a business-friendly format.

The dashboard includes multiple pages covering:

- Financial transaction overview
- Revenue by payment method and transaction status
- Monthly and weekday revenue trends
- Key Performance Indicators (KPIs)
- Completed revenue analysis
- Transaction-level performance insights

The dashboard uses interactive visuals and filters to explore revenue and transaction patterns.

## How to Run

1. Clone the repository
2. Make sure the CSV file is available in the `data/` folder
3. Open the notebook from the `notebooks/` folder
4. Install the required Python libraries
5. Run the notebook cells
6. Open the Power BI file from the `Power-BI/` folder to explore the dashboard
